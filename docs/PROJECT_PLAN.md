# CivicSakhi AI

## Theme
Theme 8 – AI for Societal Good

## Project Goal

Build an AI-powered multilingual civic complaint platform that helps citizens report, understand, and track civic issues using AI.

## Problem

Citizens struggle to report complaints because:
- They don't know the responsible department.
- Existing portals are difficult to use.
- Language barriers exist.
- Complaint tracking lacks transparency.

## Solution

CivicSakhi AI enables citizens to submit complaints using text, voice, or images. AI automatically analyzes the complaint, recommends the department, assigns priority, generates a structured complaint, and allows users to track complaint status.
